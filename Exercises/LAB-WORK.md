# An ABSAD Company 

has introduced a discount policy for customers, according to the following policy:  Discount is based on the type of customer and the quantity of order.
For individual customers:
If order is 12 or more packets, the discount is 30%; if less than 12 packets, discount is 0%
For retailers:
If order is less than 12 packets, 15% discount; if order is between 13 to 48 packet, discount is 30%; If order is between 48 to 84 packet, 40% discount; If order more than 85 packet, discount is 50%.
Write a java program to keep on displaying three option items in a menu (1. individual customer, 2. Retailer, 3. Exit) for a user to select from; it then compute and display discount status according to the company’s discount policy. 
Note: The program will only stop running when user select option 3.

Hint: use do while repetition statement and if..else selection statement
